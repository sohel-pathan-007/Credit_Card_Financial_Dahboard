**Credit Card Financial & Customer Analytics Project**

**Project Overview**

An end-to-end data analytics project to analyze credit card transactions and customer data.
The project covers data cleaning, SQL database management, data analysis, and Power BI dashboard development.

**Project Workflow**

Raw Data → Excel Cleaning → SQL Database → SQL Analysis → Power BI Dashboard

**Key Work**

- Cleaned and prepared data using Excel.
- Created relational tables "cc_info" and "cust_info" in SQL.
- Used SQL queries, joins, filtering, and aggregations for analysis.
- Used Power Query for data transformation.
- Created DAX measures and KPIs in Power BI.
- Built interactive dashboards using charts, tables, and slicers.
- Analyzed revenue, transactions, interest, customer demographics, income, card categories, and spending patterns.

**Dashboards**

**Credit Card Transaction Report**

Analyzes revenue, interest, transaction amount, transaction count, expenditure type, transaction methods, customer jobs, and card categories.

**Credit Card Customer Report**

Analyzes customer age, gender, income, education, marital status, job, dependents, states, revenue, and customer satisfaction.

**Technology Stack**

SQL | Excel | Power BI | Power Query | DAX

**Project Objective**

To analyze customer and transaction data and create useful business insights through interactive Power BI dashboards.
